# 点弹幕开发

## 入口

点弹幕的主入口是：

```java
BulletApi.builder(world)
```

对应公开类型：

- `BulletApi`
- `BulletBuilder`
- `BulletHandle`
- `BulletSnapshot`

## 最小示例

```java
BulletApi.builder(world)
    .position(new Vec3d(x, y, z))
    .velocity(new Vec3d(vx, vy, vz))
    .life(80)
    .damage(3.0f)
    .spawn();
```

## 常用参数

- `position(Vec3d)`
  - 生成位置，必填
- `velocity(Vec3d)`
  - 初速度，必填
- `life(int)`
  - 生命周期，单位 tick
- `damage(float)`
  - 默认伤害
- `texture(String)`
  - 纹理路径
- `color(int)`
  - 颜色
- `size(float)`
  - 尺寸
- `rendererType(String)`
  - 客户端渲染器类型
- `collisionShape(ICollisionShape)`
  - 几何碰撞形状
- `hitBehavior(IBulletHitBehavior)`
  - 该弹幕自己的命中逻辑
- `motionController(IBulletMotionController)`
  - 该弹幕自己的运动控制
- `onTick(Consumer<IBulletActor>)`
  - 轻量每 tick 回调
- `collisionFilter(IBulletCollisionFilter)`
  - 该弹幕自己的命中过滤规则
- `onlyPlayer(boolean)`
  - 是否只对玩家有效
- `shooter(EntityLivingBase)`
  - 发射者
- `shooterHeldItem(ItemStack)`
  - 发射时手持物快照
- `attackSourceInfo(AttackSourceInfo)`
  - 伤害来源标记
- `preset(...)`
  - 复用已注册弹幕预设

## 该怎么选扩展点

### 想给单颗弹加命中效果

用：

- `hitBehavior(IBulletHitBehavior)`

适合：

- 命中后自毁
- 命中后改伤害
- 命中后附加状态
- 命中后分裂、生成子弹、触发特效

### 想改飞行方式

优先用：

- `motionController(IBulletMotionController)`

轻量逻辑也可以用：

- `onTick(Consumer<IBulletActor>)`

适合：

- 跟踪弹
- 加速度弹
- 摆动弹
- 分阶段飞行弹

### 想统一观察或拦截所有弹幕命中

不要绑在 builder 上，改用：

- `BulletCollisionEvent`

适合：

- 全局友伤规则
- 全局减伤系统
- 和别的附属 mod 联动
- 调试统计

## 命中处理链

当前点弹幕命中时的顺序是：

1. 发布 `BulletCollisionEvent`
2. 事件中可访问 `CollisionContext`
3. 若事件未取消，则执行 `hitBehavior`
4. 若 `context.canceled == false`，再应用默认伤害

`CollisionContext` 中常用字段：

- `bullet`
- `world`
- `hitEntity`
- `damage`
- `canceled`
- `shooter`
- `shooterHeldItem`
- `attackSource`

示例：

```java
.hitBehavior(ctx -> {
    ctx.damage = ctx.damage * 1.5f;
})
```

## 自定义数据

`set(...)` 会写入 `customData`，通常给渲染器或附加逻辑读取：

```java
BulletApi.builder(world)
    .position(pos)
    .velocity(vel)
    .rendererType("model_json")
    .set("model", "minecraft:furnace")
    .set("variant", "inventory")
    .set("scale", 0.45f)
    .spawn();
```

注意：

- `customData` 更适合传配置，不适合塞复杂运行时状态
- `customData` 不会自动变成额外伤害逻辑

## 常见范式

### 直线弹

- 固定 `velocity`
- 不设置额外运动控制

### 跟踪弹

- `motionController(...)`
- 或 `onTick(...)` 中调整速度

### 模型弹

- `rendererType("model_json")`
- 用 `set(...)` 传模型参数

### 纯表现弹

- 不设置 `collisionShape`

### 只对玩家生效的弹

- `onlyPlayer(true)`

## 常见问题

### 为什么 `spawn()` 报错

通常是因为：

- 没有设置 `position`
- 没有设置 `velocity`
- 在客户端调用了 `spawn()`

### 为什么看得见但没有命中

通常是因为：

- 没有设置 `collisionShape`
- `collisionFilter` 拦截了目标
- 阵营关系解析拒绝了目标
- `CollisionContext.canceled` 被设成了 `true`
