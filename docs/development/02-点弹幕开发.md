# 点弹幕开发

## 入口

普通点弹幕的开发入口是：

```java
BulletApi.builder(world)
```

对应类：

- `com.smd.bulletapi.api.BulletApi`
- `com.smd.bulletapi.api.builder.BulletBuilder`

## 最小示例

```java
BulletApi.builder(world)
    .position(new Vec3d(x, y, z))
    .velocity(new Vec3d(vx, vy, vz))
    .life(80)
    .damage(3.0f)
    .spawn();
```

## 常用参数

- `position(Vec3d)`
  - 生成位置，必填
- `velocity(Vec3d)`
  - 速度，必填
- `life(int)`
  - 生命周期，单位 tick
- `damage(float)`
  - 默认伤害
- `texture(String)`
  - 纹理路径
- `color(int)`
  - 颜色
- `size(float)`
  - 尺寸
- `rendererType(String)`
  - 渲染器类型
- `collisionShape(ICollisionShape)`
  - 碰撞箱
- `onCollision(Consumer<CollisionContext>)`
  - 命中回调
- `onTick(Consumer<Bullet>)`
  - 每 tick 回调
- `onlyPlayer(boolean)`
  - 是否仅对玩家生效
- `shooter(EntityLivingBase)`
  - 发射者
- `shooterHeldItem(ItemStack)`
  - 发射者手持物快照
- `attackSourceInfo(AttackSourceInfo)`
  - 伤害来源标记

## 自定义数据

`set(...)` 用于向 `customData` 写入额外字段，通常给渲染器或扩展逻辑读取：

```java
BulletApi.builder(world)
    .position(pos)
    .velocity(vel)
    .rendererType("model_json")
    .set("model", "minecraft:furnace")
    .set("variant", "inventory")
    .set("scale", 0.45f)
    .spawn();
```

注意：

- `customData` 不会自动参与伤害判定
- `customData` 适合传小规模配置，不适合塞复杂运行时状态

## 碰撞回调链

点弹幕命中时会走这条链：

1. `BulletCollisionEvent`
2. `CollisionContext`
3. `builder.onCollision(...)`
4. 如果没有取消，再应用默认伤害

`CollisionContext` 中可用字段：

- `damage`
- `canceled`
- `shooter`
- `shooterHeldItem`
- `attackSource`

可以在回调中修改伤害或取消默认处理：

```java
.onCollision(ctx -> {
    ctx.damage = ctx.bullet.getDamage() * 1.5f;
})
```

## 常见范式

### 直线弹

直接设置固定速度。

### 跟踪弹

在 `onTick` 中修改速度。

### 模型弹

设置：

- `rendererType("model_json")`
- `model`
- `variant`
- `scale`
- `rot_mode`
- `tint`

### 无碰撞表现弹

不设置 `collisionShape` 即可。

## 常见问题

### 为什么 `spawn()` 报错

通常是因为：

- 没有设置 `position`
- 没有设置 `velocity`
- 在客户端调用了 `spawn()`

### 为什么看得见但没有命中

通常是因为：

- 没有设置 `collisionShape`
- 被 `canBulletCollide(...)` 过滤掉
- `onCollision` 中取消了默认伤害
