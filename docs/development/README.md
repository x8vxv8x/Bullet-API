# BulletAPI 开发文档

本目录面向附属 mod 作者，重点说明当前版本中哪些内容属于稳定公开扩展面，哪些只是内部实现。

当前文档按“附属 mod 作者如何接入”来组织，而不是按内部实现目录组织。

## 扩展边界

当前版本请按注解理解可用范围：

- `@PublicApi`
  - 附属 mod 可以直接调用，属于稳定公开 API
- `@SpiApi`
  - 附属 mod 可以实现或注册，属于稳定 SPI
- `@InternalApi`
  - 内部实现细节，外部不要依赖

这意味着：

- `api` 目录是主入口，但不是唯一公开面
- `spi`、`event`、少量 `common` / `client.render` 类型同样属于正式扩展面
- `server`、`network`、内部管理器、客户端缓存不应作为附属 mod 的依赖入口

## 文档目标

本套文档主要回答四件事：

1. 我该直接调用哪些 API
2. 我该实现哪些接口接入运行时
3. 我该监听哪些事件做联动
4. 我绝对不该依赖哪些内部类
