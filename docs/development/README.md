# BulletAPI 开发文档

本目录用于集中存放 BulletAPI 的开发说明，面向二次开发者。

当前文档结构：

- [01-API总览.md](./01-API总览.md)
  - 对外公开 API、包结构、推荐入口
- [02-点弹幕开发.md](./02-点弹幕开发.md)
  - 普通点弹幕的创建、回调、常见用法
- [03-激光开发.md](./03-激光开发.md)
  - 激光创建、持续束、命中回调、视觉参数
- [04-召唤物开发.md](./04-召唤物开发.md)
  - 蓝图注册、链式覆写、碰撞型/弹幕型/激光型召唤物
- [05-渲染扩展.md](./05-渲染扩展.md)
  - 注册新的弹幕渲染器、激光渲染器、复用 `model_json`
- [06-碰撞扩展.md](./06-碰撞扩展.md)
  - 自定义碰撞箱、碰撞检测接口说明
- [07-网络同步与发包.md](./07-网络同步与发包.md)
  - 内部同步链路、发包职责、扩展同步对象的思路

阅读建议：

1. 先看 `01-API总览`
2. 按需要阅读点弹幕、激光或召唤物开发
3. 需要做可视化扩展时再看渲染扩展
4. 需要做判定扩展时再看碰撞扩展
5. 只有要改同步结构时才看网络同步与发包
