# 对象查询与控制速查

这篇文档只做一件事：把当前版本里最常用的 `Spawn / Handle / Battlefield / Snapshot` 入口放在一页里，方便快速查。

## Battlefield

统一入口：

```java
Battlefield battlefield = Battlefield.of(world);
```

### 点弹幕

```java
battlefield.bullets().count();
battlefield.bullets().contains(id);
battlefield.bullets().ids();
battlefield.bullets().all();
battlefield.bullets().get(id);
battlefield.bullets().handle(id);
```

### 激光

```java
battlefield.lasers().count();
battlefield.lasers().contains(id);
battlefield.lasers().ids();
battlefield.lasers().all();
battlefield.lasers().get(id);
battlefield.lasers().handle(id);
```

### 召唤物

```java
battlefield.summons().count();
battlefield.summons().contains(id);
battlefield.summons().ids();
battlefield.summons().all();
battlefield.summons().get(id);
battlefield.summons().ownedBy(ownerId);
battlefield.summons().handle(id);
```

## 常见选择

- 要生成点弹幕/激光：用 `Builder`
- 要生成召唤物：用 `SummonApi.spawn(...)`
- 要控制单个已存在对象：用 `Handle`
- 要查世界中的对象集合：用 `Battlefield`
- 要读精简只读状态：用 `Snapshot`
