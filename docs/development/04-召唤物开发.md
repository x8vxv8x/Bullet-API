# 召唤物开发

## 入口

召唤物开发入口：

```java
SummonApi.builder(world)
```

注册蓝图入口：

```java
SummonApi.registerBlueprint(new MySummonBlueprint());
```

## 两种开发方式

### 1. 蓝图继承类

适合正式预设。

推荐基类：

- `AbstractSummonBlueprint`
- `AbstractOrbitingSummonBlueprint`
- `AbstractContactSummonBlueprint`

### 2. 链式覆写

适合测试和生成时临时改参数：

```java
SummonApi.builder(world)
    .owner(player)
    .definition("bulletapi:ram_wisp")
    .slotCost(2)
    .damage(5.0f)
    .spawn();
```

## 运行流程

`SummonManager` 每个服务端 tick 会执行：

1. 校验主人和目标
2. 触发目标选择
3. 执行移动控制
4. 更新位置
5. 执行本体碰撞
6. 执行攻击模板
7. 向客户端同步快照

## 三类常见召唤物

### 1. 本体碰撞类

关键配置：

- `targetSelector`
- `moveController`
- `collisionShape`
- `bodyCollisionIntervalTicks`

### 2. 子弹发射类

关键配置：

- `targetSelector`
- `moveController`
- `attackPattern(new ShootBulletPattern(...))`

### 3. 激光发射类

关键配置：

- `targetSelector`
- `moveController`
- `attackPattern(new ShootLaserPattern(...))`

## 伤害来源标记

召唤物相关伤害会带：

- `SUMMON_BODY`
- `SUMMON_CHILD_BULLET`
- `SUMMON_CHILD_LASER`

这允许外部系统按来源做增伤、特效、过滤。

## 本体碰撞链路

本体碰撞由 `SummonManager` 统一处理。

命中链路：

1. `BulletCollisionEvent`
2. `CollisionContext`
3. `summon.onCollision(ctx)`
4. 默认伤害

`CollisionContext` 可用判定：

- `isSummonSource()`
- `isSummonBody()`
- `isSummonChildBullet()`
- `isSummonChildLaser()`

## 蓝图示例

```java
public class MySummonBlueprint extends AbstractContactSummonBlueprint {
    public MySummonBlueprint() {
        super("bulletapi:my_contact_summon");
    }

    @Override
    protected void configure(SummonDefinition.Builder builder) {
        builder
            .life(6000)
            .slotCost(1)
            .damage(4.0f)
            .texture("bulletapi:textures/entity/bullet.png")
            .color(0xFFAA66)
            .size(0.6f)
            .collisionShape(new SphereShape(0.3))
            .bodyCollisionIntervalTicks(2)
            .moveController(new RamStrikeMoveController());
    }
}
```

## 常见问题

### 为什么召唤失败

先检查：

- 是否服务端生成
- 是否设置了 `owner`
- 槽位是否足够

### 为什么召唤物存在但不攻击

通常是：

- 没有目标
- `targetSelector` 不匹配
- `attackRange` 太小
- `attackPattern` 为空

### 为什么本体不撞人

通常是：

- 没有 `collisionShape`
- `bodyCollisionIntervalTicks` 过大
- `moveController` 没让它真正贴近目标
