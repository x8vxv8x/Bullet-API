# 激光开发

## 入口

激光开发入口：

```java
LaserApi.builder(world)
```

对应公开类型：

- `LaserApi`
- `LaserBuilder`
- `Battlefield`
- `LaserHandle`
- `LaserSnapshot`

## 最小示例

```java
LaserApi.builder(world)
    .start(start)
    .direction(direction.normalize())
    .maxLength(24.0)
    .life(20)
    .damage(3.0f)
    .spawn();
```

## Builder / Handle / Battlefield / Snapshot

### Builder

负责生成一束激光。

```java
LaserHandle handle = LaserApi.builder(world)
    .start(start)
    .direction(direction)
    .maxLength(24.0)
    .life(20)
    .spawnHandle();
```

### Handle

负责控制单束已存在的激光。

常用方法：

- `exists()`
- `remove()`
- `setTransform(start, direction)`
- `setLength(length)`
- `setLife(life)`
- `snapshot()`

### Battlefield

负责查询当前世界中的激光集合。

```java
Battlefield.Lasers lasers = Battlefield.of(world).lasers();

int count = lasers.count();
List<Integer> ids = lasers.ids();
List<LaserSnapshot> all = lasers.all();
LaserSnapshot one = lasers.get(id);
LaserHandle handle = lasers.handle(id);
```

### Snapshot

`LaserSnapshot` 是精简只读对象，当前包含：

- `id`
- `start`
- `direction`
- `length`
- `thickness`
- `life`
- `damage`
- `onlyPlayer`
- `penetrate`
- `blockStops`
- `attackSource`

## 常用参数

- `start(Vec3d)`
  - 起点
- `direction(Vec3d)`
  - 方向
- `maxLength(double)`
  - 最大长度
- `thickness(float)`
  - 粗细
- `life(int)`
  - 生命周期
- `damage(float)`
  - 默认伤害
- `color(int)`
  - 主颜色
- `rendererType(String)`
  - 激光渲染器类型
- `penetrate(boolean)`
  - 是否穿透多个目标
- `blockStops(boolean)`
  - 是否被方块阻挡
- `followShooter(boolean)`
  - 是否跟随发射者
- `startOffset(Vec3d)`
  - 世界空间偏移
- `startOffsetLocal(Vec3d)`
  - 本地空间偏移
- `eventIntervalTicks(int)`
  - 对同一目标的重复触发间隔
- `hitBehavior(ILaserHitBehavior)`
  - 激光自己的命中逻辑
- `collisionFilter(ILaserCollisionFilter)`
  - 激光自己的命中过滤规则
- `shooter(EntityLivingBase)`
  - 发射者
- `shooterHeldItem(ItemStack)`
  - 发射时手持物快照
- `attackSourceInfo(AttackSourceInfo)`
  - 伤害来源标记
- `preset(...)`
  - 复用已注册激光预设

## 什么时候该用什么扩展点

### 想给这一束激光单独加命中逻辑

用：

- `hitBehavior(ILaserHitBehavior)`

适合：

- 命中后附魔法效果
- 命中后扣不同伤害
- 命中后让激光自毁或改状态

### 想控制这一束能不能打到目标

用：

- `collisionFilter(ILaserCollisionFilter)`

适合：

- 排除某类生物
- 排除主人或同阵营目标
- 只命中特定标签对象

### 想做全局联动或跨模组兼容

用事件：

- `LaserCollisionEvent`

适合：

- 全局减伤规则
- 护盾系统
- 战斗统计
- 调试记录

## 命中处理链

当前激光命中时的顺序是：

1. 发布 `LaserCollisionEvent`
2. 事件中可访问 `LaserCollisionContext`
3. 若事件未取消，则执行 `hitBehavior`
4. 若 `context.canceled == false`，再应用默认伤害

示例：

```java
.hitBehavior(ctx -> {
    ctx.damage = ctx.damage * 0.75f;
})
```

## 短命激光与持续激光

### 短命激光

```java
.life(10)
```

适合：

- 瞬发束
- 脉冲束
- 技能触发类视觉

### 持续激光

```java
.life(-1)
```

适合：

- 炮台束
- 跟随型持续束
- 召唤物维持束

持续激光通常需要外部逻辑决定何时移除。

## 跟随发射者

如果使用：

```java
.followShooter(true)
```

服务端会根据发射者位置和视线更新这束激光。

如果你需要：

- 固定方向束
- 固定起点束
- 由外部 AI 或召唤物维护的激光

则应使用：

```java
.followShooter(false)
```

然后由外部逻辑配合 `LaserHandle.setTransform(...)` 维护位置和方向。

例如：

```java
LaserApi.handle(world, laserId).setTransform(start, direction);
```

## 现有渲染器类型

- `laser_beam`
- `laser_blast`
- `laser_none`
- `laser_poly`

这些是客户端渲染器类型，不影响服务端命中判定。

## 常用视觉参数

不同渲染器会读取不同的 `customData` 字段。

例如 `laser_poly` 常见字段：

- `alpha`
- `poly_sides`
- `core_scale`
- `shell_scale`
- `pulse_amp`
- `pulse_speed`
- `shell_color`
- `shell_color_end`

例如 `laser_blast` 常见字段：

- `segment_len`
- `core_scale`
- `shell_scale`
- `shell_color`
- `shell_color_end`

## 同步说明

激光仍然是服务端权威对象：

- 服务端决定长度、阻挡、命中、伤害
- 客户端只接收快照并做表现
- 附属 mod 不应直接构造内部同步包

## Battlefield 查询什么时候更合适

优先用 `Battlefield.of(world).lasers()` 的情况：

- 查询当前世界激光总数
- 查找某个技能是否仍有束存活
- 做调试面板或统计输出

优先用 `LaserHandle` 的情况：

- 你已经拿到了激光 id
- 你要持续维护同一束激光的位置、方向或长度

## 常见问题

### 为什么看起来跟不上发射体

优先检查：

- `followShooter` 是否符合预期
- 是否重复生成短命束而不是维护同一束
- 是否应该改为外部主动 `setTransform(...)`

### 为什么激光打不到目标

优先检查：

- `start` 是否正确
- `direction` 是否正确归一化
- `collisionFilter` 是否过滤掉了目标
- `blockStops` 是否提前截断
- 阵营关系解析是否拒绝了目标

### 为什么改方向了但客户端看起来不稳定

优先检查：

- 是否在服务端调用 `LaserHandle.setTransform(...)`
- 是否每 tick 在维护同一束激光，而不是重复生成新激光
- `followShooter` 与外部维护方式是否冲突
