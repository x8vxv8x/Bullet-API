# 激光开发

## 入口

激光开发入口：

```java
LaserApi.builder(world)
```

对应类：

- `com.smd.bulletapi.api.LaserApi`
- `com.smd.bulletapi.api.builder.LaserBuilder`

## 最小示例

```java
LaserApi.builder(world)
    .start(start)
    .direction(direction.normalize())
    .maxLength(24.0)
    .life(20)
    .damage(3.0f)
    .spawn();
```

## 常用参数

- `start(Vec3d)`
  - 起点
- `direction(Vec3d)`
  - 方向
- `maxLength(double)`
  - 最大长度
- `thickness(float)`
  - 粗细
- `life(int)`
  - 生命周期
- `damage(float)`
  - 伤害
- `color(int)`
  - 主颜色
- `rendererType(String)`
  - 激光渲染器类型
- `penetrate(boolean)`
  - 是否穿透多个目标
- `blockStops(boolean)`
  - 是否被方块阻挡
- `followShooter(boolean)`
  - 是否跟随发射者
- `startOffset(Vec3d)`
  - 世界空间偏移
- `startOffsetLocal(Vec3d)`
  - 本地空间偏移
- `eventIntervalTicks(int)`
  - 对同一目标重复触发间隔
- `onCollision(Consumer<LaserCollisionContext>)`
  - 命中回调
- `shooter(EntityLivingBase)`
  - 发射者
- `attackSourceInfo(AttackSourceInfo)`
  - 伤害来源标记

## 短命激光与持续激光

### 短命激光

```java
.life(10)
```

特点：

- 倒计时结束后自动移除
- 适合瞬发束和脉冲束

### 持续激光

```java
.life(-1)
```

特点：

- 不会自然倒计时结束
- 需要外部手动移除，或由宿主逻辑控制结束
- 适合召唤物持续束、炮台束

## 跟随发射者

如果使用：

```java
.followShooter(true)
```

则服务端每 tick 会根据发射者位置和视线更新激光。

如果你需要：

- 固定方向束
- 定点束
- 召唤物自定义跟踪束

则应使用：

```java
.followShooter(false)
```

并由外部逻辑维护起点和方向。

## 碰撞回调链

激光命中时会走：

1. `LaserCollisionEvent`
2. `LaserCollisionContext`
3. `builder.onCollision(...)`
4. 如果没有取消，再应用默认伤害

示例：

```java
.onCollision(ctx -> {
    ctx.damage = ctx.laser.getDamage();
})
```

## 现有渲染器类型

- `laser_beam`
- `laser_blast`
- `laser_none`
- `laser_poly`

这些注册发生在客户端初始化阶段。

## 常用视觉参数

不同渲染器会读取不同 `customData` 字段。

例如 `laser_poly` 常见字段：

- `alpha`
- `poly_sides`
- `core_scale`
- `shell_scale`
- `pulse_amp`
- `pulse_speed`
- `shell_color`
- `shell_color_end`

例如 `laser_blast` 常见字段：

- `segment_len`
- `core_scale`
- `shell_scale`
- `shell_color`
- `shell_color_end`

## 客户端同步说明

激光是服务端权威对象。

- 服务端负责长度计算、碰撞和伤害
- 客户端收到快照后立即应用
- 渲染时再做 `prev -> current -> partialTicks` 插帧

一般开发者不需要手动发内部激光同步包。

## 常见问题

### 为什么看起来跟不上发射体

应先检查：

- 是否用了错误的 `followShooter`
- 是否服务端实际上在重复生成短命束
- 是否同步频率过低

### 为什么激光打不到目标

应检查：

- `start` 是否正确
- `direction` 是否正确归一化
- `blockStops` 是否提前截断
- `attackSourceInfo` 或阵营过滤是否拦截了目标
